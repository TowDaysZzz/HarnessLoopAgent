# ADR 0006：笔记事实来源与 RAG 投影

## 状态

已接受。

## 决策

Agent MySQL 是笔记业务事实来源，RAG 是可删除、可重建的搜索投影。创建笔记时，Agent 先在本地事务中保存原始内容并写入 Outbox，再异步提交 RAG 索引任务。

每条笔记使用不可变的 `external_note_id` 关联 RAG 文档，所有写请求带幂等键。RAG 返回 `pending` 只能使本地状态进入 `indexing`；只有任务明确完成后才能标记为 `indexed`。

删除采用软删除与异步投影删除：先标记 `delete_pending` 并写 Outbox，RAG 删除成功后标记 `deleted`。RAG 删除失败时保留原始笔记及失败状态，以便重试和审计。

本期只实现新增、查询和删除。笔记更新以及保留/清理历史版本的两种策略延期，设计记录保留在 roadmap 中。

## 后果

- RAG 故障或重建不会造成业务笔记丢失。
- 写入为最终一致，需要状态查询和后台重试。
- 检索结果必须按可信用户与固定个人知识库范围过滤。
